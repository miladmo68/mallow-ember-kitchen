# Mallow & Ember · two-day delivery plan

## Product
An original restaurant concept and responsive digital storefront for a Toronto neighborhood table. Fictional menu and availability are illustrative; ordering and reservations remain in the browser and never represent real purchases or bookings.

## Why this release
Previous projects are fleet operations, exhibition planning, personal finance, and clinic scheduling. This project serves diners, uses an editorial storefront rather than a dashboard, and centers on menu discovery, pickup ordering and table reservation.

## Day 1 milestones
1. Framework, static deployment scaffold and brand foundation.
2. Typed seasonal catalog, dietary taxonomy and cart arithmetic.
3. Browser-local order/cart state with valid transitions.
4. Reservation availability and conflict-safe capacity model.
5. Editorial visual system and licensed real photography references.
6. Responsive menu and booking interactions.

## Day 2 milestones
Complete all visible journeys, add edge/error/empty states and accessibility, strengthen tests, author Playwright desktop/phone QA, include screenshot-first README and deployment workflow, run factory validation, publish only after success.
